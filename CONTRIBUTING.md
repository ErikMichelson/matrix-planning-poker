# Contributing

Contributions are welcome. Please follow these guidelines when opening an issue or pull request.

## Before opening a pull request

- **Issue first:** Discuss proposed features in an issue before opening a pull request.
  Pull requests without a related discussion issue may be closed. Simple bug fixes are exempt.
- Keep changes focused and explain what problem they solve.
- Use the repository's tooling to maintain code quality and style. This project uses `pnpm`.
  Run `pnpm run check` before submitting changes, use `pnpm run fix` to apply formatting fixes.
  Git hooks and CI also help enforce the project's conventions, please do not bypass the hooks.
- Use conventional commits. See [conventionalcommits.org](https://www.conventionalcommits.org/en/v1.0.0/)
  for more information.

## AI-assisted contributions

- AI tools may assist with contributions, but the human contributor owns the submitted work and is
  responsible for it.
- You must review the code and be able to explain every part of it.
- All communication and documentation must be written by a human.
- Maintainers do not want to discuss contributions with an AI bot. This results in a ban.

## Community and review

- Be excellent to each other. Keep discussions respectful and constructive.
- Maintainers reserve the right to reject pull requests without providing further reasons.
- Misbehavior may result in maintainers banning a user from interacting with this repository.
