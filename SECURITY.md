# Security reports

Please report security vulnerabilities using
[GitHub's vulnerability reporting feature](https://github.com/erikmichelson/matrix-planning-poker/security/advisories/new).

Keep reports as concise as possible. Include a summary, a concise description, and a minimal
reproducible example if possible.

The [AI-assisted contributions policy](CONTRIBUTING.md#ai-assisted-contributions) applies especially
to communication about security reports: all communication must be human-written. Maintainers do
not want to discuss reports with an AI bot.
